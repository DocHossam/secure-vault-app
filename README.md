# 🛡️ Secure Vault - تطبيق الحفظ المشفر المحلي

تطبيق موبايل متكامل مبني باستخدام **Flutter** لحفظ البيانات الحساسة والمهمة محلياً 100% دون الحاجة إلى أي إنترنت أو سيرفرات خارجية (Offline First & Zero-Knowledge).

---

## ✨ المميزات الرئيسية (Key Features)

1. **النسخ بنقرة واحدة (One-Tap Copy):**
   - نسخ فوري للـ API Key أو رقم الفيزا مباشرة من القائمة الرئيسية بضغطة زر واحدة.
   - **مسح تلقائي للذاكرة (Clipboard Auto-Clear):** مسح محتوى الحافظة تلقائياً بعد 30 ثانية (قابلة للتعديل) لحماية بياناتك من قراءة أي تطبيقات أخرى.

2. **دعم بطاقات الدفع والفيزا (Credit & Debit Cards):**
   - واجهة كارت واقعية تحاكي البطاقة وتتغير ألوانها حسب اختيارك (6 أنماط Gradient).
   - تعرف تلقائي على نوع البطاقة: **Visa, Mastercard, Amex, وميزة (Meeza)**.
   - نسخ رقم الكارت بضغطة واحدة، ونسخ الـ CVV بضغطة منفصلة.
   - إمكانية إخفاء وإظهار الأرقام الحساسة.

3. **إدارة مفاتيح الـ API والأسرار البرمجية (API Keys & Secrets):**
   - تخزين المفتاح الرئيسي والـ Client Secret ورابط الـ Endpoint وتحديد البيئة (Production, Staging, Dev).
   - إخفاء الـ Token تلقائياً برموز `••••••••` مع زر لكشفه.

4. **المستندات والصور المشفرة (Encrypted Photos & Documents):**
   - إمكانية التقاط صور بالكاميرا أو اختيار صور من المعرض (مثل بطاقة الرقم القومي، الباسبور، كروت العمل).
   - **تشفير الصور محلياً بـ AES-256:** الصور لا تظهر في معرض الهاتف العادي، بل يتم تشفيرها وتخزينها في مساحة التطبيق الخاصة.
   - عارض صور داخلي يدعم التكبير والتحريك (Pinch-to-zoom).

5. **بحث فوري وتصنيف متقدم (Instant Search & Filters):**
   - شريط بحث سريع يبحث في الأسماء، الملاحظات، الـ Tags، والـ 4 أرقام الأخيرة من الفيزا.
   - أزرار فلترة سريعة (الكل، مفاتيح API، بطاقات بنكية، ملاحظات، صور، المفضلة ⭐).

6. **أمان محلي فائق (Local Security & Biometrics):**
   - قفل التطبيق بـ **Master PIN** مكون من 6 أرقام.
   - دعم فتح التطبيق بالبصمة أو بصمة الوجه (**Biometric Authentication**).
   - تشفير البيانات على القرص بواسطة **AES-256-CBC**.

7. **نسخ احتياطي محلي مشفر (Encrypted Local Backup):**
   - تصدير ملف نسخة احتياطية مشفر (`.vault`) لحفظه في مكان آمن.
   - استيراد النسخة الاحتياطية بسهولة عند تغيير الهاتف.
